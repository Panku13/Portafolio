## 📊 **Análisis de Desempeño de las Tiendas de Alura Store**

Este proyecto forma parte del **Challenge de Alura**, enfocado en fortalecer habilidades de **Análisis de Datos** y **Ciencia de Datos** mediante un caso práctico realista.  
El reto consiste en ayudar al **Sr. Juan**, propietario de la cadena **Alura Store**, a decidir **qué tienda vender** para financiar un nuevo emprendimiento.

Para ello, se realizó un análisis integral de las **4 tiendas actuales**, evaluando su desempeño comercial y operativo a partir de datos reales de ventas, ingresos y reseñas de clientes.

---

## 🎯 **Objetivos del Proyecto**

- 📈 **Comparar el rendimiento** de las cuatro tiendas de Alura Store.  
- 💰 **Identificar la tienda menos eficiente**, considerando ingresos, volumen de ventas, satisfacción del cliente y desempeño operativo.  
- 📊 **Visualizar los resultados** mediante gráficos claros y representativos.  
- 🧩 **Emitir una recomendación final**, sustentada en datos, sobre cuál tienda debería vender el Sr. Juan.
